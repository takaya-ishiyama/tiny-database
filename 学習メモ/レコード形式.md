- checksum
    - レコードが壊れていないか確認するための値
    - 保存時にkeyやvalueから計算し、読み込み時に再計算して比較する
    - ファイルの一部欠損や書き込み途中のクラッシュを検出できる

- key length
    - keyが何バイトあるか
    - "name"ならUTF-8で4 bytes
    - この値を使って、ファイルからkey部分だけを切り出す

- value length
    - valueが何バイトあるか
    - "Taro"なら4 bytes
    - valueの終端を特定するために使う

- tombstone
    - このレコードが「登録・更新」なのか「削除」なのかを表す印
    - 例えば 0 = 通常, 1 = 削除
    - tombstoneは「墓石」という意味で、削除されたことを記録する仕組み
